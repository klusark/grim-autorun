# Test of 7240c11: "GRIM: Do not use the moving actors colision mode, always use sphere"

In the original Grim Fandango, the collision mode of the actor that walks makes no difference: only the other actor's
mode counts. Before this commit, ScummVM gave a different result when the walking actor's mode was box. With the
commit, it gives the same result for every mode of the walking actor, as the original does.

## How it was tested

The same Lua script and the same data files were run on the original executable (v1.01, through a launcher that fixes
every frame at 17 ms) and on ScummVM (`--sim-fps=60`). No game files were used. The set, the costume and the model (a
box 0.4 x 0.3 x 1.8 m, no textures) were generated by a script, so the whole test can be shared.

Two ScummVM builds were tested, both with the same test-only additions: a detection entry for the test data and
`--sim-fps`. Neither addition touches collision code.
- **before**: f909c9d8822, the commit's parent on master
- **after**: f909c9d8822 + 7240c11

One actor (the mover) walks forward for 100 frames into a second actor (the wall), at 20 degrees to the wall's face.
Every combination of mover mode and wall mode (off, box, sphere) is run, at collision scale 0.4 and 1 for both actors.
Each run logs the mover's final (x, y).

## Results

"all" means the three mover modes (off, box, sphere) end at the same point.

| scale | wall mode | original | ScummVM before | ScummVM after |
|---|---|---|---|---|
| 0.4 | off | all (-0.382, 0.097) | all (-0.381, 0.097) | all (-0.381, 0.097) |
| 0.4 | box | all (-0.513, -0.090) | **differ:** off (-0.441, 0.040) / box (-0.381, 0.097) / sphere (-0.441, 0.040) | all (-0.441, 0.040) |
| 0.4 | sphere | all (-0.574, -0.279) | **differ:** off (-0.381, 0.097) / box (-0.169, 0.054) / sphere (-0.381, 0.097) | all (-0.381, 0.097) |
| 1 | off | all (-0.382, -0.303) | all (-0.381, -0.303) | all (-0.381, -0.303) |
| 1 | box | all (-0.788, -0.884) | **differ:** off (-0.435, -0.854) / box (-0.381, -0.303) / sphere (-0.435, -0.854) | all (-0.435, -0.854) |
| 1 | sphere | all (-0.486, -1.604) | **differ:** off (-0.520, -1.348) / box (0.725, 0.612) / sphere (-0.520, -1.348) | all (-0.520, -1.348) |

- **Box wall, box mover:** before the commit, the mover walked through the wall ("Collision between box and box not
  implemented!"). With the commit, it is stopped, as it is with the other mover modes.
- **Sphere wall, box mover:** before the commit, the mover took the mixed box/sphere path. At scale 1 it ended on the
  far side of the wall. With the commit, it is a sphere, as in the original.
- **Wall mode off:** the mover walks freely in every build.

The original's `Collision_TestActorAgainstOthers` (0x4939f0) reads only the other actor's mode. It treats the walking
actor as a sphere: its model's radius times its collision scale. It never reads the walking actor's own mode.

## What this does not show

On master, the mover still ends at a different point than in the original, with or without this commit. The rows
differ in where the mover stops, not in whether its own mode matters. Those differences have other causes:
- the walking actor's sphere is raised by half the model's height and the other actor's is not, so at scale 0.4 a
  sphere wall is never hit at all;
- the box collision response is not the original's.

A branch with those fixed (grim-actor-fixes, which also ignores the walking actor's mode) matches the original in every
row above, to within 1e-3.

The test also walks the mover into the wall with `WalkActorTo`. That walk collides on the original but on no ScummVM
build tested, so it is a separate bug and not part of this commit.

The mover walks in at an angle because the original gives NaN positions when an actor moves straight into a face of a
box: its box slide turns about a zero axis.

## The test

```lua
-- The collision mode of the actor that moves (ScummVM commit 7240c11, "Do not use the moving actors collision mode, always
-- use sphere"). On the original, Collision_TestActorAgainstOthers (0x4939f0) treats the actor that moves as a sphere
-- whatever its own mode is; only the mode of the other actor counts (0 off, 1 box, 2 sphere). Each test walks a mover
-- with mode m into a wall actor with mode w: the results of one w must be the same for every m.
--
-- The mover walks in at 20 degrees: a move straight into a face of a box gives NaN positions on the original
-- (Collision_BoxSlide turns the slide about a zero axis).

cr_cm_actor = function(name, x, y, yaw)
	local a = LoadActor(name)
	PutActorInSet(a, "cr_flat.set")
	PutActorAt(a, x, y, 0)
	SetActorRot(a, 0, yaw, 0)
	SetActorCostume(a, "cr_box.cos")
	return a
end

cr_cm_case = function(key, m, w, how, scale)
	MakeCurrentSet("cr_flat.set")
	-- (at scale 1 the spheres are 1.9 m across: the mover starts further away)
	local a = cr_cm_actor("cr_cm_mover", 0.2, (scale == 1 and -1.9) or -1.5, 20)
	local b = cr_cm_actor("cr_cm_wall", 0, 0.2, 0)
	SetActorFollowBoxes(a, TRUE)
	SetActorWalkRate(a, 1)
	SetActorCollisionMode(a, m)
	SetActorCollisionMode(b, w)
	SetActorCollisionScale(a, scale or 0.4)
	SetActorCollisionScale(b, scale or 0.4)
	cr_frames(1)
	if how == "to" then
		WalkActorTo(a, -0.3, 1.6, 0)
	end
	local i = 0
	while i < 100 do
		if how == "forward" then
			WalkActorForward(a)
		end
		if mod(i, 20) == 0 then
			cr_pos(key .. "_f" .. i, a)
		end
		break_here()
		i = i + 1
	end
	cr_pos(key .. "_end", a)
	cr_log(key .. "_walking", IsActorMoving(a))
	SetActorCollisionMode(a, 0)
	SetActorCollisionMode(b, 0)
	PutActorInSet(a, nil)
	PutActorInSet(b, nil)
end

cr_cm_test = function(m, w, how, scale)
	local key = "cm_" .. how .. "_m" .. m .. "_w" .. w
	if scale then
		key = "cm_" .. how .. "_s" .. scale .. "_m" .. m .. "_w" .. w
	end
	cr_test(key, function()
		cr_cm_case(%key, %m, %w, %how, %scale)
	end)
end

-- every mover mode against every wall mode, walking forward and walking to a point behind the wall
local hows = { "forward", "to" }
local h = 1
while hows[h] do
	local w = 0
	while w <= 2 do
		local m = 0
		while m <= 2 do
			cr_cm_test(m, w, hows[h])
			m = m + 1
		end
		w = w + 1
	end
	h = h + 1
end

-- and walking forward at collision scale 1
local w = 0
while w <= 2 do
	local m = 0
	while m <= 2 do
		cr_cm_test(m, w, "forward", 1)
		m = m + 1
	end
	w = w + 1
end
```
